# 从宣传目标到浏览任务

“宣传合唱团”先拆成访客任务：认识团队 → 看唱过什么 → 看具体演出与图片 → 深入了解成员和指挥。六页结构复用已有内容，既避免首页堆满资料，也让具体问题有明确入口。

| 选择 | 对应任务与取舍 |
| --- | --- |
| 首页突出进入演出档案 | 初次访问先知道对象，再进入具体内容 |
| 节目单按场次展开 | 保留完整资料，同时减少扫读时的长列表负担 |
| 照片缩略图与放大查看 | 先浏览，再按需要查看细节；关闭后焦点回原入口 |
| 移动导航与Escape关闭 | 给窄屏和键盘使用者明确的进入、退出方式 |
| 静态页面 | 当前需求以内容浏览为主，无明确登录、报名或后台需求 |

视觉借用舞台与音乐厅坐标组织页面，内容主体仍是真实团队与演出资料。此次发布包整理沿用既有设计，没有另做网站改版。

这些解释基于已有页面和源代码，不宣称制作前已完成正式访谈，也未证明某种交互提高了转化。下一步如正式服务团队，应先观察信息能否找到、移动端是否易读、图片是否顺畅，以及目标访客网络能否打开网站；当前没有这类用户测量结果。
