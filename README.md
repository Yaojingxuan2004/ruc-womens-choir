# RUC 女子合唱团 · 演出与团队展示网站

**把分散的演出、照片和团队资料，组织成一份可以浏览的合唱团档案。**

个人兴趣项目，2026.08使用JavaScript与AI协作迭代。出发点是宣传合唱团，让访客了解团队、浏览演出，再进入相册、成员、荣誉与指挥资料。

[Sites作品地址](https://ruc-womens-choir.yaojingxuan2004.chatgpt.site/) · [完整产品案例](docs/product-case.md) · [内容与交互设计](docs/design-decisions.md)

## 我的工作与交付

从团内经历提出宣传需求，组织已有内容、明确页面结构与浏览任务，并结合自身JavaScript基础使用Vibe coding完善展示和交互。AI参与代码与视觉迭代；不将全部代码归为个人独立手写。

- 六个页面：首页、演出、成员、相册、荣誉、指挥。
- 演出节目单展开、照片放大、移动导航、Escape关闭和图片关闭后焦点返回。
- 静态HTML、CSS与JavaScript；页面无需登录或后端。现有内容为4场专场、13个相册条目，非用户增长指标。

## 本地浏览

在仓库根目录执行（需要Python 3，仅用作静态服务器）：

```sh
python -m http.server 8772 --bind 127.0.0.1 --directory public
```

打开 http://127.0.0.1:8772/ ，按Ctrl+C停止。页面没有构建依赖，`public/`包含所引用的本地图片。原Sites构建包装未纳入，因为这个版本可以独立作为静态站浏览。
